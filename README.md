# Jordan Bastian - Portfolio

Aspiring Technical Product Manager & Engineering Manager.

This portfolio showcases the journey and projects of Jordan Bastian, bridging the gap between complex software architecture and human psychology.

## Tech Stack
- **Framework:** React (Vite)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React (Custom SVGs for brand logos)
- **Deployment:** Optimized for static hosting (Vite build)

## Project Structure
- `src/Portfolio.jsx`: Master component containing all logic and layout.
- `public/images/`: Consolidated directory for all portfolio assets.
- `src/main.jsx`: Entry point for the application.

## Getting Started
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Build for production: `npm run build`
